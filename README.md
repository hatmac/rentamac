# rentamac
Hatmac is a platform designed to make macOS computing accessible on demand. We provides a convenient way for developers, teams, and businesses to rent Mac devices remotely without the upfront cost of purchasing and maintaining Apple hardware.

Whether you're building iOS and macOS applications, testing software across Apple platforms, running macOS-specific workloads, or setting up a dedicated development environment, Hatmac offers a flexible alternative to owning physical Mac devices.
